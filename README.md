# SkinAI: Multimodal AI Framework for Skin Disease Diagnosis

**SkinAI** is a comprehensive research project developing a multimodal AI system for accurate and inclusive dermatological diagnosis. This repository contains the front-end web platform used to showcase the research objectives, methodology, and progress.

## 🚀 Key Features
- **Multimodal Fusion**: Combines visual analysis (ConvNeXt) with clinical symptom data.
- **Natural Language Integration**: BERT-driven text and voice analysis for symptom intake.
- **Explainable AI (XAI)**: Transparent severity assessments and diagnostic reasoning.
- **Inclusivity Focus**: Optimized for high accuracy across diverse skin types and tones.
- **Personalized Care**: Knowledge-based treatment and skincare recommendation system.

## 🛠️ Technology Stack
- **Framework**: React 19 + Vite
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Design**: Custom CSS Grid System

## 📁 Project Structure
- `/src/pages`: Core content including Research Domain, Milestones, and Documents.
- `/src/components`: Reusable UI elements like Section Headers and System Mockups.
- `/src/assets`: Research papers, presentation slides, and team assets.

## 🚦 Getting Started
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/SkinAI-Multimodal-Diagnosis.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run the development server**:
   ```bash
   npm run dev
   ```
